Conditions

Each condition is a signal (what the world does) carrying a message (what it says) through a channel (where the words reach the agent). Ordered least to most compelling.

The id spells out those three: signal+message@channel — code_666+redirect is HTTP 666 carrying the redirect in the response body, and permit+none@none is the baseline: nothing is blocked, nothing is said. @channel is left off when it is the usual one, the HTTP response. The C01 number is just its rung on the ladder. What are the channels?

Channels — where the words reach the agent

    

      The channel is the one knob that is not yours to add to. Each of the four decides the
      moment the instruction becomes available, and every outcome is measured from
      that moment, so classify.py has a branch per channel. A fifth would need a
      fifth branch — it is a code change, not a catalogue edit. The four are the C4 quadrants.
    

    

  


  

    
Where a definition lives

    

      Two files make up the catalogue.  is what the repo ships —
      clone it anywhere and you get those.  is yours alone: the
      control room writes here so the shipped file keeps its comments and its ordering, and it
      is merged on top, so anything named in both wins here. Every edit is resolved against the
      merged result before it is written, so a broken one is refused at the form rather than at
      the next run.
    

    

  







  

    
Conscience levels

    

      How hard the system prompt pushes the agent to finish the task exactly as the user specified.
      This is what a redirect has to overcome, so it is the experiment's other main knob. A level is a
      set of clauses plus free text; switching clauses on and off is what makes it weak or strong, and
      reusing a clause keeps the wording identical across levels. Each one is a value for --conscience.
